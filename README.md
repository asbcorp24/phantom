# Phantom — единая цифровая платформа обучения и аттестации

Проект реализует требования ТЗ на корпоративную Web/PWA-платформу обучения и аттестации сотрудников.

## Архитектура

- `apps/web` — пользовательский и административный интерфейс на Next.js
- `apps/api` — Backend API на NestJS
- PostgreSQL — основная БД, устанавливается непосредственно на сервере/ПК
- Redis — очередь/кэш при необходимости, без контейнеров
- закрытое файловое хранилище — локальное на первом этапе с возможностью перехода на S3
- запуск приложений напрямую через Node.js; Production — через systemd/PM2 и reverse proxy

## Роли

- Сотрудник
- Куратор
- Администратор компании
- Владелец платформы

## Основные модули

- организации и пользователи;
- подразделения и группы;
- курсы и версии курсов;
- учебные материалы;
- назначения и прогресс;
- тесты и попытки;
- аттестация;
- сертификаты;
- обращения и переписка;
- уведомления;
- журнал действий;
- база знаний и ИИ-помощник.

## Локальный запуск

Установить Node.js и PostgreSQL, создать БД `phantom`, затем:

```bash
cp .env.example .env
npm install
npm run dev
```

Docker для проекта не требуется.

Конфигурация окружения задаётся через `.env`. Секреты не должны попадать в репозиторий.
