# Phantom — единая цифровая платформа обучения и аттестации

Проект реализует требования ТЗ на корпоративную Web/PWA-платформу обучения и аттестации сотрудников.

## Архитектура

- `apps/web` — пользовательский и административный интерфейс на Next.js
- `apps/api` — Backend API на NestJS
- PostgreSQL — основная БД
- Redis — очереди/кэш
- S3-совместимое закрытое хранилище — учебные материалы и сертификаты
- Docker Compose — локальная инфраструктура

## Роли

- Сотрудник
- Куратор
- Администратор компании
- Владелец платформы

## Основные модули

- организации и пользователи;
- подразделения и группы;
- курсы и версии курсов;
- учебные материалы;
- назначения и прогресс;
- тесты и попытки;
- аттестация;
- сертификаты;
- обращения и переписка;
- уведомления;
- журнал действий;
- база знаний и ИИ-помощник.

## Быстрый старт

После добавления приложений:

```bash
docker compose up -d postgres redis minio
npm install
npm run dev
```

Конфигурация окружения задаётся через `.env`. Секреты не должны попадать в репозиторий.
